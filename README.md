## Projects

| Project | Description | Tools |
|---|---|---|
| [Customer Lifetime Value Prediction](customer-lifetime-value/) | Predicts CLV from Google Analytics e-commerce data to identify high-value customer segments and the marketing strategies most effective at driving them. | Python, SQL |
| [Revenue Forecasting](revenue-forecasting/) | Sales trend analysis and revenue forecasting across three linked datasets, with a logic map and an accompanying [interactive Tableau dashboard](https://public.tableau.com/views/RevenueAnalysis_16612808748220/Rev_forc?:language=en-US&:display_count=n&:origin=viz_share_link). | Python, Tableau |
| [Airline Customer Satisfaction Analysis](airline-satisfaction-analysis/) | Identifies which service factors most drive satisfaction and dissatisfaction from survey data. | Python |
| [Market Basket Analysis](market-basket-analysis/) | Association rule mining on shopping cart data to uncover product affinities and generate item recommendations. | R |
| [Data Anonymization Tool](data-anonymization-tool/) | A client-facing Streamlit app (plus underlying script) that anonymizes and merges metrics CSVs for secure external data sharing, built to support client reporting without exposing sensitive identifiers. | Python, Streamlit |
| [Metrics Pipeline Automation](metrics-pipeline-automation/) | Scripts that automate aggregating recurring metrics datasets and correcting systematic errors from upstream auto-generated data. | Python |
